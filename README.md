
# 🛒 E-Commerce Customer Behavior & Sales Dashboard

An interactive Power BI analytics project designed to analyze customer purchase patterns, demographics, product preferences, and sales performance across an e-commerce platform.


---

## 🛠️ Tech Stack & Tools

* **Business Intelligence & Reporting:** Power BI Desktop
* **Data Modeling & Calculations:** DAX (Data Analysis Expressions)
* **Data Preparation:** Power Query (M)
* **Data Source:** CSV (E-commerce transactional & demographic data)

---

## 📈 Key Insights & Analytical Features

* **Customer Segmentation:** Breakdown of customer segments by age groups, gender, purchase frequency, and membership tiers.
* **Sales & Revenue Dynamics:** Total sales, average order value (AOV), and revenue distribution across categories.
* **Behavioral Analysis:** Evaluation of browsing-to-purchase ratios, discount dependency, return rates, and customer review scores.
* **Interactive Slicers:** Dynamic filters for date ranges, customer demographics, device types, and product categories.

## 🚀 How to View and Run the Dashboard

1. **Clone the Repository:**
```bash
git clone [https://github.com/moha0808/Customer-Behavior-Dashboard.git](https://github.com/moha0808/Customer-Behavior-Dashboard.git)

```


2. **Open in Power BI:**
* Launch [Power BI Desktop](https://powerbi.microsoft.com/).
* Open `Customer Behavior Sales Dashboard.pbix`.


3. **Data Refresh:**
* If prompted to refresh data sources, set the file path of `E-commerce Customer Behavior - Sheet1.csv` to its location on your local machine.
